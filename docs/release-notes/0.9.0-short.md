0.3.3 からの主な変更です。
- git の作業（変更の記録・ブランチ・GitHub への送信）を、「作業」「ブランチ」「全体図」の画面で行えるようになりました。実行される git のコマンドも画面に出ます。
- プルリク（変更されたファイル・レビュー・マージ）、Actions（テストやビルドの失敗を、直す順に積んで表示）、リリース（マイルストーンからノートを作る）を入れました。
- 「アクティビティ」で、レビューを頼まれた・期限が近いなどの「あなたがすること」と、チームの動きが分かります。
- タスクの一覧を表でも見られるようになり、まとめ方と「保存した見方」を選べます。見積もり・サブイシュー・テンプレート・関連・変更の履歴が加わりました。
- ボードを「未整理」と「着手済み」に分け、下の机に付箋を置くと自分の担当になります。
- 「オーバービュー」で、いまの状況とチームのペース（ベロシティ・サイクルタイム）が分かります。マイルストーンをスプリントとして使え、バーンダウンが出ます。
- ガントに、見積もりからの仮の日程と、マイルストーンの期限の線が出ます。
- アカウントがない人の入口と、チームへの招待（送る・受ける）をアプリに入れました。「GitHub でログイン」で、トークンを作らずに、選んだリポジトリだけを期限つきで許可して入れます。
- インターネットにつながらないときも Issue を見たり変えたりでき、つながったら GitHub に送ります。
- テーマ（黒板・ホワイトボード・クエスト）とサイドバーの位置を選べます。アイコンとマニュアルも新しくなりました。
- 日本語入力で変換を確定する Enter や取り消す Esc で、送られたり閉じたりする不具合などを直しました。
- データは GitHub にあるので、更新してもそのまま使えます。アプリが Issue を消すことはありません。
くわしくは、「設定 → その他」の「マニュアルを開く」をご覧ください。
