# Life Manager 1.0.0

1.0.0 では作業の流れとチームの知らせを大きく変えました。「作業をする」では Issue を選んでから完了にするまで、作業報告とコミット・プッシュをくり返します。「あなたがすること」が増えると画面の角に知らせが出て、困ったときは 🆘 で助けを求められます。
テーマは 9 つになり、マイルストーンはステージセレクトのように選んで、達成すると大きく祝います。Android のスマホでも使えます（試用版）。

## 主な新機能

### 作業をする

- 左の欄の「作業」を「作業をする」にしました。上の段の ① 作業を選ぶ → ② 作業報告 → ③ コミット・プッシュ → ④ 完了 の順に進めます。② と ③ は完了にするまでくり返します。
- ① ではマイルストーンを選んで Issue を探し、どのブランチで作業するか（ブランチを作る、切り替える、今のブランチのまま）を決めて始めます。始めると自分が担当になり、状態が「進行中」になります。
- ② ではやったことやわかったことを、Issue にコメントとして書き込みます。前のコメントも下に出ます。
- ③ では変更にチェックを入れ、要約を書いて「コミットしてプッシュ」を押します（Ctrl＋Enter でも）。「コミットだけ」もあります。
- ④ では今の状態に合わせて、プルリクを作る、レビューとマージをする、Issue を閉じる、のボタンが出ます。マージしたあとも、同じブランチで続けられます。
- ① に当てはまる Issue がないときは「📊 ボードでタスクを足す」（マイルストーンがなければ「🎯 マイルストーンを作る」）が出ます。
- コミットの前の見張り: Unity の Library や Temp、Unreal Engine の Saved や Intermediate、Visual Studio の .vs、100 MB をこえるファイルなど、コミットしない方がよいものにチェックが入っていると、コミットを止めます。「.gitignore に足す」で書き足して、チェックも外せます。
- プッシュを断られたとき（GitHub に、この PC にないコミットがある）は、知らせの「プルしてからプッシュ」で取り込んでから送り直せます。
- 始めるときに作るブランチの名前は、Issue の題名から作ります。別の作業のブランチにいるときは、main の最新から作ります。始めると「（名前） が作業開始しました」のコミットを付けて、すぐ GitHub に送ります。
- ① の「今の作業」から「作業を止める…」と「引き継ぐ…」ができます。作業のブランチを GitHub に送ってから、Issue にコメントを残します。引き継ぐと担当が相手になり、相手に知らせが届きます。受け取った人が ① でその作業を選ぶと、そのブランチで続けます（コミットの履歴ごと引き継げます）。
- 終えたブランチ（マージしたもの、プルリクを出さずに完了にしたもの）は、① と ④ で既定のブランチに戻ったり、消したりできます。GitHub からも消せるのは、リーダー（リポジトリの管理者）だけです。
- まちがえて違うブランチで始めたときは、① で今の作業の行を押すと、題名のブランチで始め直せます。
- ①、③、④ から Issue を開けます。
- 1 台の PC でアカウントを切り替えても、今の作業はアカウントごとに分かれます。

### おしらせと「助けを求める」

- 「あなたがすること」（レビューや修正を頼まれた、担当の期限、名前を呼ばれた、チェックの失敗 など）に新しいものが出てくると、画面の角の「おしらせの窓」で知らせます（PC。出す角は 設定 → 通知 で選びます）。アプリを前に出していなくても出ます。
- 期限は「もうすぐ（3 日前から）」「今日」「過ぎた」のときに 1 回ずつ知らせます。レビュー、修正の依頼、承認は、プルリクごとに 1 回です。片付いたあとにまた頼まれたら、また知らせます。
- 起動したときにたまっていたものは、1 つにまとめて「あなたがすることが 12 件あります ・ 新しく 3 つ」のように知らせます。
- 窓の × を押しても終わらず、インジケーター（画面の右下の小さなアイコン）に残って知らせを受け取ります（設定 → 通知 で「終了する」にもできます）。
- 上のバーの 🔔 で、知らせのりれき（60 日）を見られます。
- Issue の詳細や「作業をする」の 🆘 で、困っていることと、いっしょに送るもの（ブランチや失敗した git など）を添えて、チームの人を呼べます。呼ばれた人には、まとめずに目立つ知らせが届きます。片付いたら「解決しました」で知らせます。
- コメントに「@名前」と書くと、その人に知らせが届きます。

### ホーム（オーバービューとヒストリー）

- オーバービューに「メンバーの今」を足しました。メンバーごとに、最後に動いた時刻と、進行中のタスクが出ます。名前を押すと、その人の担当のタスク一覧が開きます。
- ヒストリーに「今日のあなた」を足しました。今日終えたタスクと、今日のコミットの数が出ます。「🌙 今日はここまで」で小さく祝い、「📓 日誌を書く」に進めます。続けた日数は数えません。
- ヒストリーで、マイルストーンの達成が外から滑り込んで光る帯で出ます。タスクの完了や、🆘 に答えたことも飾ります。

### 見た目

- テーマが 9 つになりました。前からの黒板、ホワイトボード、クエストに、ナイト、デイタイム、スプリング、ウィンター、金魚、文鳥を足しました。ボード、机、背景の動き、完了のお祝いが、テーマごとに変わります。
- はじめて起動したときに、テーマの小さな見本を見ながら選べます。
- アプリが前にないときや、最小化やインジケーターに隠したときは、動きを止めます（重くならないように）。

### ボード

- タブが 3 つになりました: 📥 未整理、🔥 着手済み、🔍 確認待ち（チェック待ち、動作確認、完了承認待ち）。着手済みには「ブロック」の板も出ます。
- 板のいちばん下の「＋ ここにタスクを追加」で、その板に白紙の付箋が出ます。名前を書いて Enter で、その状態のタスクとして貼られ、続けて書けます。
- 下の机（自分の担当）を、縁のでっぱりで上へ引き出せます。押すといちばん上まで広がり、広げた机にはボードと同じ付箋が並びます（PC とスマホ）。

### マイルストーン

- マイルストーンの画面を、ゲームのステージセレクトのようにしました。時間の順の道の上で選ぶと、期間、進み、最近のペースとの比べ、かかわった人が大きなパネルに出ます。
- クエストのテーマではマイルストーンが「ボス」になり、残りが HP で減っていきます。
- 最後のタスクを完了にすると画面全体で大きく祝います（トロフィー、花火、ステージクリア、はんこ など）。光が集まって「ドン」と光り、数が数え上がります。音は 設定 → 表示 の「お祝いの音」で鳴らせます（はじめは鳴らしません）。
- マイルストーンを作ると、そのマイルストーンが選ばれます。「📊 ボードでタスクを足す」で、そのマイルストーンのタスクを表示したボードが開き、足したタスクはそのマイルストーンに入ります。
- 「📋 見本の計画から作る」で、企画 → プロトタイプ → α版 → β版 → 発表 の 5 つのマイルストーンと、よくあるタスク 24 件を 1 回で作れます。始める日と発表の日から、それぞれの期限を割り振ります。

### ガント

- 行を日程の順に並べます（日程のないタスクは下）。
- 先行タスクの矢印は、帯の中を通らず、後続の帯に上から入ります。交わりが少なくなるように通し、画面の外のタスクへも引きます。
- 帯か左の一覧の行に乗せると、そのタスクと先行、後続に色が付き、下の帯にタスクの内容と、先行と後続の札が出ます。押すと固定します。
- 上の段の「矢印は選んだタスクだけ」に印を付けると、乗せたタスクの矢印だけを出します。
- 「仮の日程を決める（N 件）」で、見積もりから置いた仮の日程を、まとめて決められます。タスク一覧の「☑ 選ぶ」の「見積もりから日程を決める」では、選んだタスクだけを決められます。

### 成果物（メディアビューワー）

- Issue の詳細の「成果物」のタブに、その Issue につながるコミット（メッセージで #11 に触れたコミットや、その Issue に触れたプルリクのコミット）で変わったファイルが、種類ごとに見本つきで並びます。
- 押すとメディアビューワーで、画像（スプライトシートの再生も）、音（波形）、動画、3D（glb、gltf、obj、fbx、stl）、コード、Markdown、CSV、HTML、PDF を見られます。

### 日誌

- 日誌の画面にカレンダーが付きました。タスクの期間（ガントの日程）が帯で、マイルストーンの期限が 🎯、日誌を書いた日が 📓 で出ます。
- 日を押すと、その日の予定（その日にかかっているタスクと、期限のマイルストーン）と、その日の日誌が出ます。

### アカウントとリポジトリ

- 1 台の PC で、いくつかの GitHub のアカウントを使い分けられます。「アカウントを選ぶ画面」で、ログインし直さずに切り替えられます（学校の共用の PC など。2 つ以上あると、起動したときにも出ます）。
- 左上のリポジトリを押すと「リポジトリを選ぶ画面」が出ます。開いている Issue、レビュー待ちのプルリク、チームの人数などを見ながら選べます。まだこの PC にないものは、そこでクローンできます。

### ラベル

- 「ラベル一括作成」で作る既定のラベルを、チームの仕事に要る 7 つにしました。優先（高、中、低）と、セクション（プログラマー、デザイナー、プランナー、その他）です。
- 前の「分野」は「セクション」になりました（表示するタスク、まとめる、付箋、メモなど）。前からある「分野:」のラベルも、セクションとして使えます。

### スマホ（Android、試用版）

- Android のスマホで、タスク、ボード、マイルストーン、ガント、日誌などを見て動かせます（git の作業は PC だけ）。
- 下のドックは、メニュー、ボード、マイルストーン、日誌、設定 の 5 つです。メニューには、チームの仕事、オーバービュー、あなたがすること と、すべての画面の札が並びます。
- 戻るボタンは開いているもの（詳細や下から出る板）から順に閉じます。
- タスク一覧やボードの表示するタスク、並び、まとめ方は、下から出る板で選びます。
- ガントは 1 行を 2 段（上に題名、下に帯）にし、押したタスクの先行と後続だけ、帯の根本から矢印を出します。
- 「GitHub でログイン」は、ブラウザで許可しているあいだ通信が止まっても、戻ってきたら続きから進みます。
- メニューに「🌿 ブランチ」を足しました。ブランチの履歴は GitHub から読みます。

### 言語

- 画面を英語と中国語（簡体字、繁体字）でも出せます。設定 → 表示 の「言語」で選びます。はじめは PC やスマホの言語に合わせます。
- GitHub に書く文（日誌、作業報告、ラベルの名前など）とマニュアルは日本語のままです。

### そのほか

- 作業の画面の説明文を減らしました。git の言葉の意味はマニュアルにあります。ボタンやチェックボックスに乗せると、動く git のコマンドが出ます。設定の「解説を表示する」はなくしました。
- 「アクティビティ」を「ヒストリー」にしました。「チームの仕事」で、これまでに終えたタスクの合計が出ます。
- メモや Issue を GitHub に送っているあいだは「送っています…」、送れなかったときは「送れませんでした → もう一度」が出ます。
- ブランチの画面で、見ているブランチを切り替えずにフェッチ、プルできます。
- ブランチと全体図で、アプリが自動で作るコミット（保存した見方、見積もりの単位、Issue テンプレート）も畳みます。
- ブランチの画面で、左右のブランチの履歴も薄く並びます。押すとそのブランチに移ります。
- ブランチの画面で、GitHub で消されたブランチに「⬆ GitHub にもう一度送る」が出ます。GitHub で消したブランチの控え（origin/…）は、フェッチのときに片づけます。
- 完了にしたときの知らせに「元に戻す」が付きました（6 秒ほど出ています）。まちがえて完了にしたときは、そこから戻せます。
- 上のバーの「？」（F1 でも）で、今の画面の説明をマニュアルで開きます。
- 設定 → 接続 のいちばん上に「準備のチェックリスト」を足しました。ログイン、リポジトリ、Life Manager の許可、作業フォルダ、Git、名前とメールアドレスのうち、済んでいないものに、直すところへ行くボタンが付きます。
- 「絞り込み」「フィルタ」を「表示するタスク」という言い方にそろえました。

## 直した不具合

- プルリクを作る欄の行の数、「下書きにする」の並び、「113 つ」のような数え方を直しました。版の名前のブランチ（1.0.0 など）は、マージしたときに消さないのが既定になりました。
- メディアビューワーで PDF の中のリンクを押すと、アプリの画面が外のページに置き換わってしまうのを直しました（リンクはいつものブラウザで開きます）。
- たくさんのファイルをメディアビューワーで見たときに、重くなるのを直しました。
- 成果物のタブを開くたびに、GitHub に何十回も問い合わせていたのを直しました。
- 日誌で、その日のものを UTC の日付で選んでいたのを、この PC の時刻帯で選ぶようにしました。
- 「期限切れ」の知らせを、画面と同じ期限（ガントの終了日、なければマイルストーンの期限）で決めるようにしました。
- 窓が狭いとき（画面の拡大が大きいとき）に、上のバーのボタンが重なっていたのを直しました。
- 金魚のテーマで、黒い金魚が後ろ向きに泳ぐことがあるのを直しました。
- 別の GitHub アカウントの非公開のリポジトリをクローンできなかったのを直しました。クローンの URL にアプリのアカウントの名前を入れるので、この PC の git がそのアカウントで取りに行きます。前にクローンしたリポジトリでプッシュが断られたときは、知らせからそのアカウントで行くようにできます。
- 別のブランチにいるときに作業を始めると、作ったブランチの上流が main になり、作業開始のプッシュが断られていたのを直しました（git の設定によっては main に送ってしまうおそれがありました）。
- 1 台の PC でアカウントを切り替えると、前のアカウントの「今の作業」が出ていたのを直しました。
- マイルストーンの最後のタスクを完了にした直後に、ヒストリーに達成の帯が出なかった（開き直すと出た）のを直しました。
- スマホで、ヒストリーの達成の帯の文字が、スクロールすると消えることがあったのを直しました。
- プルリクを作れないとき（GitHub App の権限の更新を、持ち主がまだ承認していない）の知らせに、承認する場所を書きました。

## 更新について

- 0.9.0 からは起動したときの更新の知らせから、そのまま更新できます。データは GitHub にあるので、更新してもそのまま使えます。
